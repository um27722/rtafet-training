# RTAFET Training — ศปอว.ทอ.

ระบบฝึกและติดตามผลภาษาอังกฤษแนวข้อสอบ RTAFET (ฟัง 60 / อ่าน 40)

- หน้าเว็บ: GitHub Pages (`index.html` ไฟล์เดียว)
- ฐานข้อมูล: Supabase — โครงสร้างใน `supabase/schema.sql` (ทุกตารางล็อก ใช้ผ่านฟังก์ชันที่ตรวจ PIN/รหัสหน่วยเท่านั้น)
- `.github/workflows/keepalive.yml` ปลุกฐานข้อมูลทุก 3 วัน (Supabase ฟรีจะหยุดเมื่อไม่มีการใช้งาน 7 วัน)

ชุดข้อสอบที่เก็บไว้สอบ (🔒) **ไม่อยู่ใน repo นี้** — อัปโหลดผ่านแดชบอร์ดผู้ติวเท่านั้น
